¿Qué es CSS?

CSS (siglas de Cascading Style Sheets, o Hojas de Estilo en Cascada) es un lenguaje de diseño gráfico o lenguaje de estilos utilizado para definir y controlar la apariencia visual, el formato y la maquetación de un documento escrito en un lenguaje de marcado, principalmente HTML

¿Qué aprenderé en este curso?

CSS te enseña a transformar el esqueleto de una página web (HTML) en una experiencia visual atractiva y funcional, permitiéndote dominar la estética y organización de un sitio. Al aprenderlo, adquieres la capacidad de dar estilo mediante colores y tipografías, organizar el espacio en la pantalla con herramientas de maquetación como Flexbox y Grid, adaptar el diseño de forma automática para que se vea perfecto en celulares, tablets y computadoras, y darle vida a la interfaz a través de efectos visuales, transiciones y animaciones interactivas.

¿Qué es CSS GRID?

CSS Grid Layout es un sistema de maquetación web bidimensional que permite dividir una página en filas y columnas para posicionar elementos de forma sencilla, versátil y coherente. A diferencia de métodos anteriores (como floats o tablas) o sistemas unidimensionales (como Flexbox), CSS Grid te da un control total y simultáneo tanto del diseño horizontal como del vertical.
